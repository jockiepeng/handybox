# 三个新工具

用户已选择图片配色提取、决策转盘、代码截图卡片，并要求先实现这三项。延续现有 Astro 静态站、双语、主题、收藏、搜索、独立地址与实现原理弹窗；不增加后端或输入持久化。

## 实现选择

采用按工具加载的浏览器模块和 Canvas 原生绘制，复用现有 UI、下载和图片校验。相比把所有功能塞进现有大模块，独立模块便于维护；相比远程截图或配色 API，本地计算符合既有隐私约定。下列具体参数为实现时的默认选择。

- I06 / image-palette：JPEG、PNG、WebP 上传/拖入、内置示例、3–10 色提取，显示 HEX/RGB 和近似占比，复制单色及 CSS，下载 CSS 与 PNG 色卡。沿用 25 MiB、24 MP、8192 px 限制。最长边缩到 160 px 后聚类，忽略 alpha < 128 的像素，单色图允许少于所选颜色数。
- T08 / decision-wheel：每行一个选项，可用 `选项 | 权重` 设置 1–100 的整数权重，最多 50 项、每项最多 60 字符。使用密码学随机源按权重选中，扇区角度也按权重分配。支持旋转动画、不重复抽取、历史与重置；耗尽后提示重置。动画遵循减少动态效果偏好，结果和指针落点一致。
- D17 / code-card：代码编辑与预览，常见语言高亮、3 套配色、纯色/渐变背景、标题、行号、字号、留白和窗口宽度，PNG 2 倍分辨率下载。相同 Canvas 同时负责预览和导出，文本只绘制、不执行。长行按画布宽度换行，限制 12,000 字符、200 输入行与导出画布面积。

## 外观

保留站点既有 #f5f7fa 背景、#ffffff 面板、#172235 文字、#64748b 次要文字和 #2267d5 操作色，深色沿用现有变量。页面字体用现有 Segoe UI / Microsoft YaHei，代码用 Consolas / monospace。桌面编辑区在左、视觉结果在右，窄屏上下排列。配色页突出图片与色块，转盘页突出大圆盘，代码页突出可下载的成品，外围设置保持安静。

## 验证与边界

覆盖纯色与透明图、损坏文件、权重边界和抽取耗尽、恶意 HTML 字符串及中文/Emoji、长行和超限输入、语言切换保留状态、真实下载、手机布局、无外部请求。配色比例是采样估计；高亮只服务展示，不保证语言解析完整；转盘为日常决策工具。
