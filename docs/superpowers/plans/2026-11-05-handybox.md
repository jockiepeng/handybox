# HandyBox Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans or independent domain delegation to implement and verify the tasks below.

**Goal:** 实现功能规划中的全部 30 个工具，简洁背景，中英文界面，GitHub Pages 静态发布。

**Architecture:** Astro 生成首页、30 个工具页面和 404。公共布局管理语言、主题、搜索、收藏和最近使用；文字工具与图片/PDF 工具按需加载。工具数据只在浏览器处理。

**Tech Stack:** Astro、原生 JavaScript、Node.js test runner、Playwright，按需打包成熟的格式解析、二维码、图片元数据和 PDF 库。

**Spec:** 根目录 `功能规划.md`，用户 2026-11-05 修订优先：全部 30 项；取消场景方向，只保留简洁背景色。采用推荐 Astro 方案；收藏、最近使用和搜索快捷键纳入实现。不包括此前明确列为范围外的外部 API、AI、OCR 或后端服务。

## Global Constraints

- 静态产物可部署在 `/handybox/`，所有工具有实际 HTML 深层地址。
- 中英文覆盖名称、表单、结果标签和错误提示，切换不丢输入。
- 纯色背景，无 WebGL、场景、自动动画或开场；浅色、深色与跟随系统。
- 输入与文件不上传、不持久保存；偏好使用 `handybox-` 存储前缀。
- 保留原始 `要求.md`；提交和推送到远程 `main` 已获得用户后续明确授权。

## Shared UI API

`src/lib/ui.mjs` exports `getLanguage()` (`zh` or `en`), `applyLanguage(root=document)`, `escapeHtml(value)`, `message(zh,en)` (current language string), `downloadBlob(blob,name)`, `copyText(text)`, and `notify(root,zh,en,kind='info')`. Modules may create their own controls with the leaf-attribute protocol. `applyLanguage` must never replace inputs or textareas. Components listen for `handybox:language` to update derived output labels without losing user input.
